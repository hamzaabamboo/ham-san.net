# Not found (404)

- **URL:** any unknown path (`/404`). Locale-aware copy comes from the URL.
- **Source:** `apps/astro/src/pages/404.astro`
- **Layout:** `MainLayout`

## Purpose

This page tells the visitor the address doesn't exist and gives the three most useful ways forward.

## Anatomy

```
404            (display italic numeral)
Page not found.
The requested route does not exist or has been relocated.
[Return home]  [Projects]  [Contact]
```

## Rules

- Buttons are sentence case in the body face (not mono caps). The primary button is amber and the others are outlined.
- The copy states what happened and where to go; it doesn't apologise.
- Detail routes (projects, tags, hobbies, notes, namecards) redirect here for unknown IDs.
