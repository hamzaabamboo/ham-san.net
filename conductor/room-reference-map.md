## 最小モデル構成案

| 要素 | 残す特徴 | 役割 |
| --- | --- | --- |
| 部屋の外形 | 主室の長方形だけ。上壁の2開口とそれぞれのカーテン、左下入口、下壁右の収納 | 実際の部屋と分かる背景 |
| 作業机 | 白い直線的な長方形の天板、モニター、ノートPC、茶色の椅子 | プロジェクトとノートへの主要導線 |
| 趣味棚 | 大型の白い複数区画棚、密な書籍・ディスク、透明展示ケース、複数のスタンディ・応援ライト。空いた小型棚に置換しない | 趣味への主要導線 |
| ぬいぐるみ | 大きな頭、伏せた胴体、前に出した手、髪と刺繍顔の寝そべり型を少数残す | 部屋固有の親しみや個性 |
| ダーツボード | 窓脇の円形と放射状の区切り、独立スタンド、下段のぬいぐるみ、床の細長い暗色マット | 部屋固有の目印。閲覧導線とは別に指定済みの最小ダーツ遊戯を接続する |
| ポスター | 写真の青系集合画、青い衣装、黄系イラスト、人物画などの特徴。配置は最新図の左・右・下壁3領域へ従う | 写真に対応する個性。文字や顔の精密複製は不要 |
| 鍵盤楽器 | 鍵盤の分かる形状とスタンド。左壁のPC机より入口側 | 部屋固有の目印。趣味への個別リンクは実コンテンツ照合が必要 |
| ビーズクッション | 棚の手前の単純な淡色形状 | 生活感を示す背景。操作対象にはしない |

机上に置いた名刺から既存namecardへ進む案を検討中。既存namecard/index.astroはnamecard/defaultへ遷移し、variantページは名刺と各種リンクを表示する。
追加候補はabout、contact、events、tags。名刺の閲覧パネルにaboutとcontactをまとめ、イベントは棚のチケットや応援グッズ、tagsはノート内の分類として扱う案。新しい割当は未確定。
趣味棚の代表物は写真で確認できる種類から選ぶ。具体的な趣味カテゴリとの対応は既存コンテンツと照合してから確定する。

## 空間の扱い

- 上壁に窓2つ。その間の中央柱にダーツスタンド。ダーツマットはそこから下方向へまっすぐ延びる。斜め配置にしない。
- PC机は左壁に沿って窓の隣に置き、着席方向は左壁向き。椅子は机の右側。机用マットは椅子の下から右へ広がり、ダーツ用マットとは別物。
- 鍵盤楽器は左壁沿いのPC机より入口側、玄関領域の手前にスタンド付きで置く。窓間のダーツスタンドへ併設しない。
- 趣味棚は右壁に沿って上側から中央まで。低い机はその左前方。ビーズクッションは低い机の下側。棚を窓壁へ置かない。
- ペンライト・長尺ライブタオルの展示面は右壁の棚より下側、収納扉に達する前の領域。発光するペンライトを複数並べ、衣類ハンガーは置かない。タオルはイベント物販として扱う。
- 入口・玄関領域は左下。入口扉は下壁の左側。収納扉は下壁の右側で、収納領域が室内側へ張り出す。
- ポスター位置は左壁のPC机上方、右壁のペンライト・タオル掛け付近、下壁の入口と収納扉の間。旧モデルの窓脇バナー位置を配置の根拠にしない。
- 机と棚の間に連続した歩行空間を確保する。写真の物量をそのまま障害物にしない。
- 主室の長方形だけを今回の空間とする。収納扉と最新図の室内側の収納領域を残し、収納内部の詳細制作は対象外。
- キッチンは今回はモデル化しない。実際には作業机側の奥に隣接することを将来用の参照情報として残す。将来の実装は未決定。
- クローズアップは各選択対象を中心に構図を決める。本文はHTMLの閲覧パネルで表示する。

## 省略するもの

- 床の袋、段ボール、包装、細かなケーブル、日用品、重複する容器。
- 衣類ラックの個々の衣類、寝具のしわ、補助机の小物群、キッチン用品。
- 全数のぬいぐるみ・フィギュア・書籍。棚には種類が伝わる代表物だけを残す。
- 最小化は物量を減らすために行う。ダーツボードや少数のぬいぐるみなど、部屋固有の特徴まで消さない。
- 写真内の画面内容、手書きメモ、人物写真、ポスターの正確な複製や文字起こし。
- クリック先のない装飾品に、追加の操作や機能を割り当てない。
